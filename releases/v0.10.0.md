# v0.10.0: comic statements for boxes, poses, props, marks and bars

## TL;DR

The `.c2m` comic format grows from a handful of statements to a full set for explainer comics: boxes that speak, arrows that start or end on figures, poses, props, bold boxes, bars, grids, repeated boxes, small text and drawn check and cross marks. Three panels now fit on a row.

## Why

v0.9.0 drew the first comics, but real comics needed a box to talk (a database saying "ready"), an arrow from a person to a system, a sad or running figure with a laptop, and a pass/fail list. Without those, agents fell back to hand-built element JSON: the two sample comics took 41 and 36 lines of JSON-building Python, and are now 12 and 9 lines of `.c2m`.

## Highlights

| What | Syntax |
|---|---|
| Panels per row | `strip 3 cols` (3 at most; 4 or more wrap) |
| Box speaks | `db says "ready"` puts the bubble above the box |
| Arrows to figures | `me -> db "asks"` may start or end on a figure |
| Poses | `me: figure sad shrug @left`; point, cheer, sit, shrug, run |
| Props | `me: figure sit laptop`; laptop, clock, server, coffee, doc |
| Bold | `b: box "Big" bold`, `stat "x" bold`: thick strokes or underline |
| Bars | `bar "Q1" 4`, scaled to the largest bar in the panel |
| Grid | `grid 2 x 2` or `grid 2 cols` for box layout |
| Same | `b: same "Cancelled"` repeats an earlier box in the same place and size with a new label |
| Small text | `note "tiny" small`, or a `~ (skipped)` line in a label, at 12 px |
| Marks | `✓ Passed` and `✗ Failed` at line start are drawn as strokes; lint ignores the stroke shapes |
| Top slot | `@top-left`, `@top`, `@top-right` put a box on its own row above the figures |

## Example

```text
strip 3 cols
panel "Check"
  me: figure sit laptop @left
  db: box "Orders"
  db says "ready"
  me -> db "asks"
```

## Upgrade notes

Nothing changes for JSON, Mermaid, doodle or existing `.c2m` input. Known limits: a box with `@top` cannot carry a bubble; side boxes sit below figures unless `@top` is used; `same` cannot be mixed with new boxes in one panel; size hints other than `small` and `~` are not supported. `c2m excalidraw --help` lists every statement in the SKETCH section.
