# v0.11.0: doodle notes by text, a syntax card, and comics that fit

## TL;DR

A doodle note can point at visible text (`"at": "Password"`) instead of pixel coordinates, `c2m excalidraw --help` opens with a one-screen syntax card, and `.c2m` panels grow to fit their boxes, with arrows that cross panels.

## Why

Writer agents drew diagrams blind and a later agent spent much of a run fixing them. Most fixes were pixel targets measured by hand, rules the help did not state up front, and comic panels too narrow for their labels.

## Highlights

| What | Syntax or behaviour |
|---|---|
| Doodle text anchor | `{"text": "the field users forget", "at": "Password"}` |
| Boxes sidecar | `<image>.boxes.json` beside the PNG: `{"width", "height", "boxes": [{"text", "x", "y", "w", "h"}]}`; scaled when its width differs |
| Matching | exact text, then case- and space-insensitive substring (tightest box); no match lists the 3 closest texts |
| Doodles pass `--strict` | note arrows are bound to the note and its target, so lint d no longer flags them |
| Syntax card | `CARD` section at the top of `c2m excalidraw --help` |
| Strip | `strip 1`, `2` or `3 cols`; 4 or more is an error that shows the rewrite |
| Arrows across panels | `a -> b "label"` at top level or between panels |
| `same` first | `b: same "X"` before any declaration declares the box |
| Panels fit | a panel widens to fit its boxes instead of clipping labels |
| Bubble on a top box | a clear error with the rewrite |

## Example

```text
c2m excalidraw --png renders/ --strict shot.doodle.json
```

writes `renders/shot.doodle.png`.
